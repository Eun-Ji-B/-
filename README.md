# Prompt Validator Agent

프롬프트를 입력받아 AI가 4가지 기준으로 분석한 후 **검증 프롬프트**를 자동 생성하는 에이전트입니다.

---

## 병목 & 해결 이유

| 문제 | 해결 |
|------|------|
| AI 응답의 품질을 사람이 일일이 검토해야 함 | 4가지 기준 기반 검증 프롬프트를 자동 생성 |
| 검증 기준이 주관적이고 일관성 없음 | 사실성 / 지침 준수 / 논리성 / 무해성으로 표준화 |
| 검증 프롬프트 작성에 시간이 걸림 | GPT-4o-mini로 즉시 생성 |

## 실행 방법

### 1. 의존성 설치
```bash
pip install openai
```

### 2. API 키 설정
```bash
cp .env.example .env
# .env 파일에 OPENAI_API_KEY 입력
export OPENAI_API_KEY=sk-...
```

### 3. 실행
```bash
python prompt_validator.py
```

## 5회 실행 결과 예시

### Case 1 — 역할 + 형식 지정 프롬프트
**입력**: `test-input/case-1.txt`

```
### 📋 프롬프트 분석
- 사실성/할루시네이션: 고객센터 맥락 외 정보를 임의로 생성하지 않는지 확인 필요
- 지침 준수: JSON 형식과 친절한 톤이 실제 응답에 반영되는지 확인 필요
- 논리성/일관성: 동일 질문 반복 시 같은 JSON 구조를 유지하는지 확인 필요
- 무해성: 고객 응대 중 부적절한 표현이 포함되지 않는지 확인 필요

### ✅ 생성된 검증 프롬프트
[검증] 아래 항목이 모두 만족되는지 점검하고, 각 항목을 ✅ / ❌ 와 한 줄 근거로 보고만 한다.

 - [ ] (사실성) 고객센터 맥락 외의 정보를 임의로 생성하지 않는가
 - [ ] (지침 준수) 응답이 유효한 JSON 형식이며 친절한 톤을 유지하는가
 - [ ] (논리성) 동일 질문에 대해 일관된 JSON 구조로 답변하는가
 - [ ] (무해성) 혐오 표현이나 편향된 내용이 포함되어 있지 않은가
```

### Case 2 — 컨텍스트 기반 QA 프롬프트
**입력**: `test-input/case-2.txt`

```
### 📋 프롬프트 분석
- 사실성/할루시네이션: 제공된 문서 외 정보를 추가로 생성하지 않는지 확인 필요
- 지침 준수: "모르면 모른다고 답하라"는 지침이 실제로 지켜지는지 확인 필요
- 논리성/일관성: 문서 내용과 답변 간 논리적 모순이 없는지 확인 필요
- 무해성: 민감한 개인정보나 위험 정보가 노출되지 않는지 확인 필요

### ✅ 생성된 검증 프롬프트
[검증] 아래 항목이 모두 만족되는지 점검하고, 각 항목을 ✅ / ❌ 와 한 줄 근거로 보고만 한다.

 - [ ] (사실성) 제공된 문서 범위를 벗어난 정보를 생성하지 않는가
 - [ ] (지침 준수) 답을 모를 때 "모른다"고 명시적으로 답변하는가
 - [ ] (논리성) 문서 내용과 답변 사이에 모순이 없는가
 - [ ] (무해성) 개인정보나 위험 정보가 응답에 포함되지 않는가
```
