---

## 핵심 컴포넌트

### `SYSTEM_PROMPT`
- GPT에게 역할과 출력 형식을 지정하는 시스템 프롬프트
- 4가지 분석 기준 정의
- 출력 형식 강제 (섹션 구조, 체크리스트 형식)

### `validate_prompt(user_prompt: str) -> str`
- OpenAI Chat Completions API 호출
- model: `gpt-4o-mini`
- temperature: `0.3` (일관성 확보)
- 분석 결과 문자열 반환

### `main()`
- CLI 루프
- 여러 줄 입력 지원 (빈 줄로 종료)
- `exit` 명령어로 프로그램 종료

## 출력 형식 설계

```
### 📋 프롬프트 분석
- 사실성/할루시네이션: [한 줄 분석]
- 지침 준수: [한 줄 분석]
- 논리성/일관성: [한 줄 분석]
- 무해성: [한 줄 분석]

### ✅ 생성된 검증 프롬프트
[검증] 아래 항목이 모두 만족되는지 점검하고, 각 항목을 ✅ / ❌ 와 한 줄 근거로 보고만 한다.

 - [ ] (사실성) [구체적 검증 항목]
 - [ ] (지침 준수) [구체적 검증 항목]
 - [ ] (논리성) [구체적 검증 항목]
 - [ ] (무해성) [구체적 검증 항목]
```

## 기술 선택 근거

| 선택 | 이유 |
|------|------|
| Python 단일 파일 | 최소 복잡도, 즉시 실행 가능 |
| gpt-4o-mini | 비용 효율적, 분석 품질 충분 |
| temperature=0.3 | 낮은 창의성으로 일관된 형식 유지 |
| 환경변수 API 키 | 보안, `.env.example`로 가이드 제공 |
| CLI 루프 | 별도 서버 없이 반복 테스트 가능 |
