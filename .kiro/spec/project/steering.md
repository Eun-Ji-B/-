# Steering — Global Rules

이 프로젝트 전반에 적용되는 전역 규칙입니다.

---

## 코드 규칙

- Python 3.8+ 호환 코드만 작성한다
- 외부 의존성은 `openai` 하나로 제한한다
- 모든 함수에 타입 힌트를 명시한다
- 환경변수는 반드시 `os.environ.get()`으로 읽는다
- API 키를 코드에 하드코딩하지 않는다

---

## 출력 규칙

- 검증 프롬프트는 반드시 `[검증]` 태그로 시작한다
- 체크리스트 항목은 `- [ ] (기준명) ...` 형식을 유지한다
- 분석 섹션과 검증 프롬프트 섹션은 항상 함께 출력한다
- 4가지 기준(사실성 / 지침 준수 / 논리성 / 무해성)은 항상 모두 포함한다

---

## 파일 규칙

- 메인 로직은 `prompt_validator.py` 단일 파일에 유지한다
- 테스트 입력은 `test-input/` 디렉토리에 보관한다
- 민감 정보(API 키 등)는 `.env`에 보관하고 `.gitignore`에 추가한다

---

## Git 규칙

- `.env` 파일은 커밋하지 않는다
- `.env.example`만 커밋한다
- 커밋 메시지는 한국어 또는 영어로 작성한다
