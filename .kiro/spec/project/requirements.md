# Requirements — Prompt Validator Agent

## 무엇을 만드는가

프롬프트를 입력받아 AI가 분석한 후 **검증 프롬프트**를 자동 생성하는 CLI 에이전트.

---

## 왜 만드는가

AI 응답의 품질을 검증하려면 "무엇을 어떻게 확인할지"를 명시한 검증 프롬프트가 필요하다.
하지만 이를 매번 사람이 직접 작성하는 것은 시간이 걸리고 기준이 일관되지 않는다.
이 에이전트는 입력 프롬프트를 분석해 표준화된 검증 프롬프트를 즉시 생성한다.

---

## 기능 요구사항

| ID | 요구사항 |
|----|----------|
| F-01 | 사용자로부터 프롬프트 텍스트를 입력받는다 |
| F-02 | 4가지 기준(사실성, 지침 준수, 논리성, 무해성)으로 프롬프트를 분석한다 |
| F-03 | 분석 결과를 `### 📋 프롬프트 분석` 형식으로 출력한다 |
| F-04 | 검증 프롬프트를 `### ✅ 생성된 검증 프롬프트` 형식으로 출력한다 |
| F-05 | 검증 프롬프트는 `[검증]` 태그 + `- [ ] (기준명) ...` 체크리스트 형식이다 |
| F-06 | 연속 입력이 가능한 루프 구조로 동작한다 |
| F-07 | `exit` 입력 시 정상 종료된다 |

---

## 비기능 요구사항

| ID | 요구사항 |
|----|----------|
| NF-01 | 단일 Python 파일로 구현 (최소 의존성) |
| NF-02 | OpenAI API (gpt-4o-mini) 사용 |
| NF-03 | temperature=0.3으로 일관된 출력 유지 |
| NF-04 | 환경변수(`OPENAI_API_KEY`)로 API 키 관리 |

---

## 검증 기준 정의

### 1. 사실성 및 할루시네이션 탐지
AI가 거짓 정보를 사실처럼 말하지 않는지, 제공된 컨텍스트 내에서만 답변하는지 확인.

### 2. 지침 준수 (Instruction Following)
프롬프트에 명시된 형식(JSON, 목록 등), 톤앤매너, 역할(Persona)을 철저히 지켰는지 검증.

### 3. 논리성 및 일관성
답변 내 논리적 모순이 없는지, 같은 질문을 반복했을 때 일관된 답변을 내놓는지 확인.

### 4. 무해성 (Safety)
혐오 표현, 편향성, 위험한 정보가 포함되어 있지 않은지 확인.
